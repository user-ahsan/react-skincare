## 🌟 Executive Summary

**Aura Botanics** is a production-grade, client-ready luxury e-commerce frontend showcasing certified 100% organic skincare, botanical haircare, and regenerative wellness rituals. Engineered as an autonomous Single Page Application (SPA) with **zero external backend dependencies**, the platform delivers a complete digital shopping experience: client-side state management, interactive catalog filtering, a 3-step diagnostic routine quiz, a multi-step checkout pipeline, live parcel tracking, an A-to-Z botanical glossary, interactive accordions, and rich editorial publications.

## 💻 Frontend Engineering Highlights

```
                          ┌─────────────────────────────┐
                          │         React 18 SPA        │
                          │   (React Router DOM v6)     │
                          └──────────────┬──────────────┘
                                         │
                 ┌───────────────────────┼───────────────────────┐
                 │                       │                       │
      ┌──────────▼──────────┐ ┌──────────▼──────────┐ ┌──────────▼──────────┐
      │    Redux Toolkit    │ │    Tailwind + Daisy │ │      Chakra UI      │
      │  Cart & Wishlist    │ │  Luxury Layouts &   │ │  Toasts, Accordions │
      │  LocalStorage Sync  │ │  Micro-Interactions │ │  & Breadcrumb Bars  │
      └─────────────────────┘ └─────────────────────┘ └─────────────────────┘
                 │
      ┌──────────▼──────────┐
      │  Zero Backend APIs  │
      │  Autonomous Client  │
      └─────────────────────┘
```

1. **State Persistence (`redux-state/CartState.js`):**
   - Redux Toolkit manages the active shopping cart, item quantities, total calculation, promo discounts, and wishlist state.
   - Automatically synchronizes with browser `localStorage`, ensuring user items and coupons survive reloads and session drops.
2. **Deterministic Data Store (`productsStore/Store.js`):**
   - 60+ meticulously curated botanical products with prices, volumes, categories, high-resolution Unsplash imagery, hover states, and multi-angle galleries.
3. **Responsive Mega-Menus (`components/NavBar.js`):**
   - Desktop hover-activated dropdown menus for *Best Sellers*, *Gift Sets*, *Shop Range*, and *Experiences*.
   - Live badge counters for bag items and wishlist count.
   - Quick-search expander with real-time route query redirection (`/shop?search=...`).
4. **Interactive Diagnostics (`components/RoutineQuizPage.js`):**
   - Dynamic 3-stage state machine analyzing skin type, primary goals, and scent notes to compute matching products and grant code `GLOW15`.
5. **Simulated Fulfillment Tracker (`components/OrderTrackingPage.js`):**
   - Client-side order tracking engine with 1-click test fill (`AB-2026-8941`) visualizing stages: *Confirmed → Cold-Pressed → Inspected → In Transit → Delivered*.

## 🚀 Quick Start Guide

### Prerequisites

- **Node.js:** v16.x or newer (Tested through Node v26.x)
- **Package Manager:** `npm` (v8.x+)

### Installation

```bash
# Clone the repository
git clone https://github.com/user-ahsan/aura-botanics-luxury-ecommerce.git

# Navigate into project directory
cd aura-botanics-luxury-ecommerce

# Install dependencies (use legacy peer deps for modern npm versions)
npm install --legacy-peer-deps
```

### Development Server

```bash
npm start
```

Runs the application in development mode at [http://localhost:3000](http://localhost:3000).

### Production Build

```bash
npm run build
```

Compiles an optimized, minified production build in `build/` ready for zero-configuration hosting on Vercel, Netlify, or AWS Amplify.

### Run Automated Audits & Demo Scripts

```bash
# Audit all 38 routes for 200 OK & zero layout overflow
node scripts/explore_audit.js

# Re-generate all 63 high-res desktop screenshots
node scripts/capture_screenshots.js

# Record the master demo video
node scripts/record_demo_video.js
```
